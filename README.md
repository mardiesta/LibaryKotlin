# Библиотека

**Библиотечный абонемент в телефоне** — Android-приложение для поиска книг, бронирования и учёта выдач. Читатель выбирает книгу и следит за сроками, а библиотекарь оформляет выдачу и возврат.

## Как это работает

| Читатель | Библиотекарь |
| --- | --- |
| Ищет книги по названию и автору | Просматривает активные брони и выдачи |
| Бронирует книгу или отменяет бронь | Подтверждает выдачу и принимает возврат |
| Просматривает свои книги и историю | Видит читателя и срок возврата |

Для входа достаточно выбрать роль. Чтобы сменить роль, выйдите из учётной записи и выберите другую. Обе роли работают с одной локальной базой на устройстве.

## Стек разработки

- **Kotlin** — язык приложения.
- **Jetpack Compose и Material 3** — интерфейс.
- **Navigation Compose и ViewModel** — навигация и состояние экранов.
- **Room и SQLite** — локальное хранение каталога, пользователей и выдач.
- **DataStore и Coroutines** — хранение сессии и асинхронная работа с данными.
- **Gradle** — сборка проекта.

Приложение работает без сервера и подключения к интернету. Данные хранятся на устройстве и не синхронизируются между устройствами. Выбор роли предназначен для демонстрации, а не для защиты реальных данных.

## Исходный код

[Открыть код Android-приложения](kotlin/)

Для сборки откройте папку `kotlin` в Android Studio или выполните:

```bash
cd kotlin
./gradlew assembleDebug
```

Инструментальные тесты Room запускаются на подключённом устройстве или эмуляторе командой `./gradlew connectedDebugAndroidTest`.
